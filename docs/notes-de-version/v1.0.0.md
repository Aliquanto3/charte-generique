# v1.0.0 : première version stable

Version 1.0.0 du plugin Claude Code `charte`. Elle contient la charte générique v2.1 et le skill qui l'applique.

## Contenu

### Charte v2.1 (`docs/CHARTE.md`)

- **Jetons** : DTCG 2025.10 dans `skills/charte/jetons/charte.tokens.json`, avec un thème sombre (par défaut) et un thème clair.
- **Rôles** :
  - fond, surface, trait, texte, primaire, bouton neutre ;
  - statuts `succes`, `alerte` et `erreur`, chacun avec ses variantes ;
  - `badge-etiquette` ;
  - palette des séries et palette divergente ;
  - `pictogramme-tuile` et `pictogramme-point`.
- **Fichiers générés dans `dist/`** : CSS, Python, Streamlit, Office, mermaid, styles matplotlib (dont `charte-document.mplstyle`), pictogramme et favicon.
- **Règles par support** : interface web, Office, graphiques, README, HTML et aperçu social.
- **Polices** : Sora SemiBold pour les titres, Atkinson Hyperlegible pour le texte, JetBrains Mono pour le code, toutes sous licence OFL et jointes au dépôt.
- **Incorporation des polices dans les documents Office** : `.odttf` obfusqué pour le DOCX, EOT pour le PPTX.
- **Contrôles** :
  - `contrastes.py` vérifie toutes les paires de rôles dans les deux thèmes ;
  - `daltonisme.py` vérifie la palette des séries sous trois types de daltonisme ;
  - `generer.py --verifier` vérifie que `dist/` est à jour.
- **Spécimens** HTML, Office, graphiques et README : ils montrent les règles appliquées, avec la preuve PDF des polices.

### Skill `charte` (`docs/SKILL-CHARTE.md`)

- `init` : pose la charte dans un nouveau dépôt avec `installer.py`. L'option `--seulement` limite l'installation à des groupes de fichiers.
- `audit` :
  - classe les couleurs et les polices d'un dépôt en `charte`, `proche`, `v1` et `hors-charte` ;
  - `--strict` sert de porte de CI ;
  - signale aussi un favicon ou un pictogramme absent et les liens du texte courant non soulignés.
- `migrer` :
  - produit un plan `auto` / `revoir` à partir de la table v1 vers v2, d'une proposition (par synonymes, puis par ΔE00) ou d'un fichier de correspondances ;
  - `--ajouter-sombre` ajoute un thème sombre d'abord ;
  - signale les variables à éclater et les aplats primaires hors bouton ;
  - migre les `@font-face`.
- **Installation** : place de marché `charte-generique` (`claude plugin marketplace add Aliquanto3/charte-generique`, puis `claude plugin install charte@charte-generique`).

### Recette

- Le skill a été éprouvé sur usine-migration-jira-demo v0.13.0.
- Ses constats ont été corrigés avant cette version.

## Limites

- Le thème sombre ajouté par `migrer` ne couvre que les variables globales (`:root`, `html`, `body`, `[data-…]`). Les variables locales à un composant restent à reprendre à la main.
- Une variable à éclater est détectée, mais pas éclatée automatiquement.
- La table de migration est figée sur `migrations/v1-vers-v2.json`. Ajouter une migration demande de modifier le code.
- L'incorporation EOT des polices dans les PPTX et le rendu PDF de preuve demandent PowerPoint et Word sur le poste. La CI ne vérifie que les paquets et les PDF commités.
- Dans le deck Office, le texte des graphiques natifs s'affiche dans la police de repli de PowerPoint.
